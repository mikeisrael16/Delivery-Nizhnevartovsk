# Доставка: Нижневартовск

**Delivery: Nizhnevartovsk** — атмосферный пиксель-арт симулятор курьера в духе *Keep Driving* и *Disco Elysium*.

Апрель в Нижневартовске. Тает грязный снег, стипендия кончилась, а за спиной — жёлтый термокороб. Студент Дима выходит на первую смену.
